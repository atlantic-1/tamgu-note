학교 실험 여건 설정

학교 기자재, 추가 예산, 탐구 시간을 적어 school-config.json 파일로 내려받습니다. 학생 화면은 이 파일을 읽어 탐구 주제와 설계를 점검할 때 참고합니다.

이 화면은 배포된 설정을 바꾸지 않습니다. 여기서 고친 내용은 이 탭에만 있고, [GitHub에 저장]을 하거나 공개용 파일을 저장소에 올려야 학생에게 반영됩니다. 탭을 닫으면 편집 내용이 사라지니 교사용 전체 백업도 내려받아 두세요.

① 기자재 목록

기본 기자재(NEIS)와 추가 기자재(구글 스프레드시트·CSV·XLSX·직접 입력)를 따로 관리해요. 학생 화면에는 두 목록을 합친 통합 목록이 쓰이고, 수량이 0인 기자재는 학생에게 보이지 않아요. 보관 위치는 교사용 정보로만 저장돼요. 모두 합쳐 최대 500행입니다.

NEIS에서 내려받은 "교과별 교구 보유현황" CSV를 고치지 않고 그대로 올리세요. 보유량이 수량으로 들어가요.

로그인하지 않아도 볼 수 있게 공유된 시트만 주소로 읽을 수 있어요. 한 번만 읽어 오는 것이며(자동 동기화 아님), 시트는 바꾸지 않아요. 비공개 시트는 시트에서 CSV나 XLSX로 내려받아 [파일 가져오기]로 올리세요.

기본 기자재와 추가 기자재를 합친 목록이에요. 고치려면 위의 해당 목록을 펼치세요. 수량이 0인 기자재는 학생에게 추천되지 않아요. 보관 위치와 검색 키워드는 학생에게 보이지 않아요.

내려받기와 저장소에 올리기

    GitHub에 저장과 공개용 파일에는 보관 위치와 검색 키워드가 들어가지 않아요. 비고, 예산, 시간, 안전 메모는 누구나 볼 수 있게 공개되니 공개하면 안 되는 내용은 적지 마세요.

    교사용 전체 백업에는 보관 위치와 검색 키워드까지 모두 들어 있어요. 저장소에 올리지 말고 선생님만 보관하세요. 다음에 [설정 JSON 가져오기 (전체)]로 다시 불러올 수 있어요.

    파일을 직접 올리는 방법
    1. [공개용 school-config.json 내려받기]로 파일을 내려받습니다. 파일 이름은 바꾸지 마세요. 교사용 전체 백업은 올리면 안 됩니다.
    2. 이 사이트의 GitHub 저장소에서 config 폴더를 엽니다.
    3. Add file → Upload files를 누르고 내려받은 파일을 끌어다 놓습니다. 같은 이름의 파일이 있으면 새 파일로 바뀝니다.
    4. 아래쪽 Commit changes를 누릅니다.
    5. 몇 분 뒤 학생 화면을 새로고침하면 새 설정이 반영됩니다. 이 화면의 [현재 배포된 설정 불러오기]로 반영 여부를 확인할 수 있습니다.

          GitHub에 저장

          저장할 저장소를 확인하고 토큰을 입력하세요. 먼저 읽기만 해서 확인하며, 다음 화면에서 내용을 확인한 뒤에야 저장돼요.

          토큰은 저장 작업 동안에만 쓰고 바로 지워요. 브라우저나 파일에 저장하지 않으며, GitHub(api.github.com)에만 보내요.

          토큰 만드는 방법
          1. GitHub의 Settings → Developer settings → Personal access tokens → Fine-grained tokens에서 새 토큰을 만듭니다.
          2. Repository access는 Only select repositories를 골라 이 사이트의 저장소 하나만 선택합니다.
          3. Permissions의 Contents만 Read and write로 바꿉니다.
          4. 만료 기간을 짧게 정하고, 토큰은 다른 사람과 공유하지 마세요. 공용 컴퓨터에서는 쓰지 마세요.
